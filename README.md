# Skill Trading Platform

Welcome to the Skill Trading Platform! This project is a collaborative platform where users can trade skills with each other. It consists of a React-based frontend and a Node.js/Express-based backend.

## Project Overview

The Skill Trading Platform allows users to:
- List skills they can offer.
- Discover skills offered by others.
- Send and receive trade requests.
- Chat in real-time with other users.
- Receive instant notifications for activities.

## How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/skill-trading-platform.git
   cd "skill-trading-platform"
   ```

2. **Setup Backend:**
   - Navigate to `backend/`.
   - Install dependencies: `npm install`.
   - Setup `.env` file.
   - Run: `npm run dev`.

3. **Setup Frontend:**
   - Navigate to `frontend/`.
   - Install dependencies: `npm install`.
   - Setup `.env` file.
   - Run: `npm run dev`.
